O teste `health.test.ts` foi migrado para o novo harness.

## 4. Como funciona — o que o diff não conta

1. **Releitura mandatória no seed (`SELECT id, name FROM artists`):**
   Numa segunda execução, `onConflictDoNothing().returning()` retorna um array vazio `[]`. Se as faixas dependessem do array retornado para mapear `artistName -> artistId`, todos os IDs ficariam nulos ou indefinidos. Ao reler todos os artistas cadastrados na base dentro da mesma transação, garantimos que o mapa `idByName` esteja sempre completo e as faixas possam ter o alvo de conflito `(artistId, title)` verificado com segurança.
2. **Aspas duplas em `"user"` no `truncateAll`:**
   A palavra `user` é palavra reservada fundamental no PostgreSQL. Executar `TRUNCATE user` causa erro de sintaxe imediato (`syntax error at or near "user"`). O uso de aspas `"user"` é mandatório.
3. **Idempotência no encerramento do harness (`stop()`):**
   O método `stop` encerra o pool `pg.Pool` antes de derrubar o container Docker via `container.stop()`, prevenindo que clientes ociosos fiquem bloqueando o encerramento do processo e evitando exceções de conexão quebrada na suíte.
4. **Distribuição de gêneros:**
   - `rock`: 8 faixas
   - `pop`: 7 faixas
   - `electronic`: 7 faixas
   - `hip-hop`: 6 faixas
   - `jazz`: 6 faixas
   - `lo-fi`: 6 faixas
     Total = 40 faixas, todas com áudios SoundHelix de 1 a 16 e durações válidas entre 120 e 380 segundos.

## 6. Armadilhas encontradas

| Sintoma                                                             | Causa                                                                                                                      | Solução                                                                                                                    |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Erros de TS em `schema.test.ts` (`artist is possibly undefined`)    | `noUncheckedIndexedAccess: true` no `tsconfig.json` faz destructuring `const [artist] = ...` inferir `Artist \| undefined` | Criada função tipada `assertDefined(value)` usando `expect(value).toBeDefined()` que estreita o tipo para `NonNullable<T>` |
