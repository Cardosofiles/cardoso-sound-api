## 1. O que foi entregue

Implementação e entrega completa do módulo de playlists privadas (`/api/v1/playlists`), abrangendo as rotas R16 a R22 da API Cardoso Sound. O módulo permite aos usuários autenticados listar suas próprias playlists de forma paginada com contagem precisa de faixas (R16), criar novas playlists com validação de limites de negócio (R17), consultar detalhes de uma playlist e suas faixas ordenadas cronologicamente por adição (R18), atualizar nome e descrição com proteção contra payload vazio (R19), excluir playlists de forma atômica e coordenada (R20), adicionar faixas do catálogo prevenindo duplicidades e condições de corrida (R21) e remover faixas individuais (R22).

Toda consulta e mutação garante isolamento estrito por usuário na cláusula SQL WHERE, assegurando que playlists alheias respondam sempre HTTP 404 Not Found (D-31) e nunca 403.

## 4. Como funciona — o que o diff não conta

1. **Isolamento por Usuário sem Vazamento por Enumeração (D-31):**
   A consulta individual de playlist utiliza compulsoriamente `.where(and(eq(playlists.id, id), eq(playlists.userId, userId)))`. Se o usuário autenticado não for o proprietário, o banco retorna `null`, o serviço dispara `NotFoundError` e a API emite HTTP 404. Jamais é emitido HTTP 403, tornando playlists inexistentes e alheias matematicamente indistinguíveis para quem realiza varredura de UUIDs.

2. **Autocontenção do Repositório (D-47):**
   Para verificar se uma faixa existe antes de adicioná-la à playlist (R21), o `PlaylistsRepository` implementa `trackExists(trackId)` diretamente contra a tabela `tracks`. O serviço não injeta `TracksRepository`, mantendo os módulos desacoplados e respeitando a regra do ESLint boundaries onde repositórios não importam outros repositórios.

3. **Dupla Proteção contra Concorrência e Conflito (D-47):**
   A adição de faixa em `POST /:id/tracks` executa primeiro `hasTrack` (para emitir HTTP 409 determinístico no fluxo normal) e na sequência executa o `insert` com `.onConflictDoNothing().returning()`. Se uma requisição concorrente inserir a mesma faixa entre a checagem e o insert, o retorno vazio é interceptado e também responde 409, impedindo que o erro `23505` (unique_violation) da chave primária composta `(playlist_id, track_id)` estoure como HTTP 500.

4. **Contagem Precisa com Subquery Correlacionada:**
   Em `listByUser`, a contagem de faixas utiliza `this.db.$count(playlistTracks, eq(playlistTracks.playlistId, playlists.id))` como subquery escalar no SELECT. Isso elimina os erros de contagem e duplicação de linhas que ocorreriam caso fosse utilizado um `LEFT JOIN` com `GROUP BY` associado a `LIMIT` e `OFFSET` paginados (Armadilha 5).

5. **Exclusão Transacional em Cascata:**
   Em `DELETE /playlists/:id`, a transação remove explicitamente as tuplas de `playlist_tracks` antes de apagar a linha em `playlists`, tornando o expurgo explícito no código mesmo havendo a constraint `onDelete: 'cascade'` no banco de dados.

| Sintoma                                                                                   | Causa                                                                                                | Solução                                                                              |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `Type '{ trackCount: number; ... }' is not assignable to type 'PlaylistRow'` no typecheck | Desestruturação de array `const [created] = ...` infere `Playlist \| undefined` em TypeScript strict | Inclusão de `if (!created) throw new Error(...)` antes de montar o retorno explícito |
| Erro `Forbidden non-null assertion` no ESLint ao comparar timestamps de faixas            | Uso do operador `!` em `addedAts[1]!`                                                                | Uso de fallback `addedAts[1] ?? 0` para comparação estrita sem asserções de tipo     |
